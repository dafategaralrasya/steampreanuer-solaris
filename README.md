# PERWIRA Digital

**Tim:** SOLARIS — *One Ecosystem, Endless Possibilities*  
**Asal sekolah:** SMKN 8 Tangerang  
**Challenge:** Vibe Engineering — Sayembara STEAMpreneur

## Deskripsi Produk

PERWIRA Digital adalah prototipe website kasir dan pencatatan usaha siswa untuk kegiatan kokurikuler **PERWIRA (Pekan Berwirausaha)** di SMKN 8 Tangerang. Aplikasi direncanakan membantu kelompok usaha kelas XI mengelola katalog barang atau jasa, mencatat penjualan, dan memantau hasil usaha sesuai hak akses.

## Tujuan Pengembangan

Membantu petugas kasir siswa melayani transaksi lebih teratur, terutama pada jam istirahat, serta menyediakan pencatatan keuangan yang dapat diperiksa kembali.

## Teknologi yang Direncanakan

- HTML, CSS, dan JavaScript
- `localStorage` untuk penyimpanan data simulasi pada browser
- Node.js untuk pengujian otomatis

## Status Proyek

**Tahap persiapan.** Spesifikasi, rencana kerja, dan kasus uji akan didokumentasikan sebelum pengembangan kode website sesuai aturan Checkpoint 1. Aplikasi belum tersedia untuk dijalankan.

## Dokumentasi dan Cara Menjalankan

Panduan instalasi, menjalankan aplikasi, menjalankan pengujian, tangkapan layar, sumber dan lisensi, serta penjelasan kontribusi tim akan dilengkapi bertahap sebelum batas pengumpulan.

## Batasan Prototipe

Website direncanakan menggunakan data simulasi dan penyimpanan lokal, bukan sistem produksi dengan autentikasi server atau sinkronisasi antardevice.
